# Uviewer-Legado

> **Uviewer-Legado** = [Uviewer](https://github.com/kirinonakar/Uviewer) + **Legado 模式网络书源**。

![Uviewer Screenshot](Uviewer/Assets/screenshot.jpg)

## 项目内容

Uviewer 是一个基于 **WinUI 3 / .NET 10** 的 Windows 阅读与看图工具（图片、文本、PDF、EPUB、压缩包、WebDAV，支持竖排与青空文库格式）。

本分支在它之上集成了 **Legado（阅读 App）同构的书源引擎**：导入 legado 书源 JSON 后，可在应用内**搜索书籍 → 看详情 → 取目录 → 在线阅读 → 整本下载**，正文经「替换净化 + 标题规则」处理后交给原生阅读器排版，与本地文档共用同一套阅读界面与快捷键。

书源引擎随宿主一同编译（`Uviewer/Services/Legado/`），**不再有独立类库**。

## 与原版 Uviewer 的差异

| 方面 | 原版 Uviewer | Uviewer-Legado |
|---|---|---|
| 内容来源 | 本地文件、压缩包、WebDAV | 增加 **legado 网络书源**（JSON 导入 / 导出 / 启停 / 编辑） |
| 阅读链路 | 打开本地文档 | **搜索 → 详情 → 目录 → 正文 → 整本下载** |
| 文本处理 | — | 替换净化（正则 / 字面 / `@js:`，可分**作用于正文 / 作用于标题**两条通道）、标题与分章规则、TXT 自动分章 |
| 目录 | 文档内标题、PDF 书签 | 书源目录（多页跟随、倒序、`formatJs`、卷章层级） |
| 缓存 | 文档级 | 章节级缓存（原文 + 净化文本），窗口统一「前 2 后 5 + 本章」；无缓存文件在阅读模式下用**内存窗口**，不落盘 |
| 进度 | 书签 / 最近文件 | 书源**断点续读**（按书源 + 书籍 URL 记录章节与位置） |
| 网络 | WebDAV | 书源 HTTP 抓取：**单一取数管线**（搜索 / 阅读 / 脚本 `java.ajax` 共用 Cookie 与会话）、每源并发限速（`concurrentRate`）、GB18030/GBK 等编码探测、超时重试、Referer 防盗链 |
| 界面 | — | 工具栏「书源」入口：书源管理、多源搜索（逐源流式渲染 + X/X 进度）、下载设置；音视频书源的结果标注「不支持音视频」 |
| 支持边界 | — | **只处理文本类书源**；音频 / 视频书源仍参与搜索，但结果只做标注，不提供播放或文本阅读（见下文「书源支持边界」） |
| 阅读模式 | 青空 / Markdown 排版开关 | 升格为**阅读模式总开关**：排版 + 替换净化 + 标题规则目录 + 章节缓存一起生效 |
| 章节导航 | 上/下一个文件 | 阅读模式下 ↑ / ↓ 改为**上一章 / 下一章**（章节取自顶栏目录） |
| 工程结构 | 单一应用工程 | 同上，书源引擎内嵌 `Services/Legado`（`Models` / `BookSources`）；另含 `Uviewer.Bench` 基准与 `Uviewer.Legado.Tests` 测试 |

除上述内容外，**看图、PDF、EPUB、青空模式、WebDAV、托盘、快捷键等能力与原版完全一致**（完整功能列表见[上游 README](https://github.com/kirinonakar/Uviewer)）。

## 阅读模式（顶栏 A 按钮）

顶栏右侧的 `A`（提示「青空/MD/阅读模式」）是一个总开关，同时决定下面四件事：

| 项目 | 开启 | 关闭 |
|---|---|---|
| 排版 | Win2D 分页画布（青空文库记法 + Markdown 解析） | 按行虚拟化的纯文本滚动 |
| 替换净化 | 读取 → 渲染之间执行替换规则 | 原样显示原文，跳过净化 |
| 目录 | 按标题规则为 TXT 分章并生成目录 | 不生成目录，顶栏目录按钮隐藏 |
| 章节缓存 | 「缓存」菜单项可用（保存 / 删除该文件的章节缓存） | 菜单项置灰，悬停提示「在阅读模式下有效」 |

打开 TXT 时是否自动开启由**有没有该文件的章节缓存**决定：有缓存则自动开启并续读上次位置，没有则不开启。
需要的话点一下 `A` 即可手动进入阅读模式（无缓存时用内存窗口，不会写盘）。

### 章节导航

阅读模式下，`↑` / `↓`（以及工具栏「上/下一个」按钮）改为**上一章 / 下一章**，章节范围就是顶栏目录下拉栏里的章节；
目录为空说明标题规则没匹配上，此时按键不做任何事（请先调整标题规则）。

### 「本章生效」标记

「替换净化规则管理」里，每条规则会在**当前章节**生效时显示标记。判定口径与净化管线完全一致：
按顺序逐条应用并比较文本，只有真正改动了本章正文的启用规则才算生效（作用域不匹配、正则不命中、替换结果相同都不算）。
界面里改完规则关闭窗口，正文会按「当前章 → 窗口内其他章」的顺序自动重刷。

### 窗口与缓存

- 阅读窗口统一为 **前 2 后 5 + 当前章 = 8 章**：只净化、只缓存窗口内的章节，窗口外不处理。
- **无磁盘缓存**的文件：章节表与窗口文本只放内存（章节表程序退出释放，窗口文本关闭文件即释放），不写盘。
- **有磁盘缓存**的文件：窗口内容来自缓存；缓存只会在你主动点「缓存」菜单时创建或删除，关闭阅读模式不会删除缓存。

## 书源支持边界

书源引擎**只处理文本类书源**（`bookSourceType = 0`），**始终不实现音视频播放**。

多源搜索会照常请求所有启用的书源：音频（`1`）/ 视频（`4`）书源命中的结果**照常列出**，只是卡片标题右侧多一个
「⚠ 不支持音视频」标注（黄色三角感叹号 + 灰色说明文字，悬停可看原因）。

- **不隐藏结果**：能搜到说明该源确实收录了这本书，用户可据此判断要不要换用文本源。
- **不做半吊子支持**：视频站常见的「打开浏览器播放 / WebView 执行脚本」链路不在实现范围内；
  点击这类卡片不会打开阅读（对话框底部会提示不支持），右侧「下载」按钮禁用，
  也不会再为它们拉取「最新章节」目录。
- **图片书源（`2`）不标注**：它不属于「音视频」，但仍按现有阅读链路处理。

## 构建

```bash
dotnet build Uviewer/Uviewer.csproj -c Debug -p:Platform=x64
dotnet test  Uviewer.Legado.Tests/Uviewer.Legado.Tests.csproj
dotnet run --project Uviewer.Bench -c Release      # 引擎性能基准（-- p0|p1|p2|p3|p4|p5|p6；p6 = 书源能力审计，基线落 results/stage4-audit-*.json）
```
